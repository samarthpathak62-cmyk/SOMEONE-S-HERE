# SOMEONE'S HERE — Godot 4 Map & Controls Test (`godot_game/`)

## 🚀 Kaise Chalayein (How to Run)
1. **Godot 4** (4.2 / 4.3 / 4.4+) open karo.
2. **Import** pe click karo aur **`SOMEONE-S-HERE/godot_game/project.godot`** select karke open karo.
3. **`F5` (Run Project)** dabao!

> **Note (`3D_Retro_World 0.01.zip` ke liye):**
> - Game start hote hi code automatically tumhare `SOMEONE-S-HERE/` folder **aur** tumhare PC ke `Downloads/` folder me `3D_Retro_World 0.01.zip` (ya unzipped folder) dhoondh kar khud extract aur load kar deta hai!
> - Agar tumne zip kisi aur drive/folder me rakha hai, toh game chalte waqt bas **`3D_Retro_World 0.01.zip` (ya uska unzipped folder) ko mouse se utha kar seedha Godot game window ke upar Drag & Drop kar do** — 2 second me poora Gas Station, Roads, Trees aur Campsite map pe spawn ho jayega!

## 🎮 Controls (Fears to Fathom Player + Map Inspector)
| Key | Action |
| :--- | :--- |
| **`W A S D`** | Chalna (First-Person Movement + Head-bob + Footsteps) |
| **`Shift`** | Daudna (Sprint) |
| **`Ctrl` / `C`** | Jhukna (Smooth Crouch — counter/props ke peeche test karne ke liye) |
| **`Space`** | Jump *(Noclip mode me Upar udne ke liye)* |
| **`Right Mouse (Hold)`** | *Fears to Fathom* Focus / Squint Zoom |
| **`F`** | Flashlight ON / OFF *(tumhara `flashlight.glb` haath me)* |
| **`P`** | Cell Phone Up / Down *(tumhara `cell_phone.glb` haath me)* |
| **`B`** | Wooden Broom haath me pakadna (`broom_wood_-_5mb.glb`) |
| **`V`** | **Noclip Fly Mode ON/OFF** *(deewar aur chhat ke aar-paar ud kar check karo ki Gas Station shop ke andar interior hai ya khali hai!)* |
| **`L`** | **Night Horror Lighting ↔ Bright Inspector Daylight** *(andhere kone saaf dekhne ke liye)* |
| **`G`** | Retro VHS / PSX Filter ON / OFF |
| **`1` / `2` / `3` / `4`** | Instant Teleport: `[1]` Gas Station, `[2]` Campsite, `[3]` All Pack Models Grid, `[4]` Cars, Items & Enemy |
| **`Tab`** | **Full Loaded Asset List** *(har model ka exact size aur mesh parts dekho + `[Teleport]` button)* |
| **`H`** | Hide / Show Controls HUD |
| **`Esc`** | Mouse Cursor free / lock |
